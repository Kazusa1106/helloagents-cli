# API 手册

## 概述

HelloAGENTS 通过特殊命令（以 `~` 开头）提供用户交互接口。这些命令触发不同的工作流模式。

## 认证方式

无需认证。命令通过自然语言输入触发。

---

## 命令接口

### 全授权命令

#### `~auto` / `~helloauto` / `~fa`

**描述:** 全授权模式，连续执行 需求分析 → 方案设计 → 开发实施

**请求格式:**
```
~auto [需求描述]
```

**示例:**
```
~auto 添加用户登录功能
```

**响应:** 执行完成后输出统一格式总结

**行为:**
- 触发授权确认
- 静默执行全流程
- 评分<7时打破静默追问
- EHRB检测时暂停警告

---

### 规划命令

#### `~plan` / `~design`

**描述:** 仅规划模式，执行 需求分析 → 方案设计，生成方案包供审查

**请求格式:**
```
~plan [需求描述]
```

**示例:**
```
~plan 重构数据库层
```

**响应:** 生成方案包（why.md + how.md + task.md）

---

### 执行命令

#### `~exec` / `~run` / `~execute`

**描述:** 执行 `plan/` 目录下已有的方案包

**请求格式:**
```
~exec
```

**前置条件:** `plan/` 目录下存在方案包

**响应:** 执行任务清单，同步知识库，迁移方案包至 `history/`

---

### 知识库命令

#### `~init` / `~wiki`

**描述:** 初始化或重建项目知识库

**请求格式:**
```
~init
```

**响应:** 扫描代码库，创建/更新知识库文件

**创建文件:**
- `CHANGELOG.md`
- `project.md`
- `wiki/overview.md`
- `wiki/arch.md`
- `wiki/api.md`
- `wiki/data.md`
- `wiki/modules/<module>.md`
- `history/index.md`

---

## 输出格式

### 状态符号

| 符号 | 含义 |
|------|------|
| ✅ | 阶段成功完成 |
| ❓ | 等待用户输入/选择 |
| ⚠️ | 警告/部分失败/需要用户决策 |
| 🚫 | 操作已取消 |
| ❌ | 严重错误/路由失败 |
| 💡 | 咨询问答 |

### 统一输出结构

```
{状态符号}【HelloAGENTS】- {阶段名称}

[阶段输出: ≤5条结构化要点]

────
📁 变更:
  - {文件路径1}
  - {文件路径2}
  ...

🔄 下一步: [≤2句建议]
```

---

## 错误码

| 场景 | 输出格式 |
|------|----------|
| 路由失败 | `❌【HelloAGENTS】- 执行错误` |
| 用户取消 | `🚫【HelloAGENTS】- 已取消` |
| EHRB警告 | `⚠️【HelloAGENTS】- 安全警告` |
| 评分不足 | `❓【HelloAGENTS】- 需求分析` + 追问 |
