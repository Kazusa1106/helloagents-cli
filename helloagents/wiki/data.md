# 数据模型

## 概述

HelloAGENTS 使用状态变量（G12）管理工作流状态，使用文件系统存储方案包和知识库。

---

## 状态变量（G12）

### CREATED_PACKAGE

**描述:** 方案设计阶段创建的方案包路径

| 属性 | 值 |
|------|-----|
| 类型 | string |
| 格式 | `plan/YYYYMMDDHHMM_<feature>/` |
| 设置时机 | 详细规划完成创建后 |
| 清除时机 | 开发实施步骤1读取后或流程终止 |

---

### CURRENT_PACKAGE

**描述:** 当前执行的方案包路径

| 属性 | 值 |
|------|-----|
| 类型 | string |
| 格式 | `plan/YYYYMMDDHHMM_<feature>/` |
| 设置时机 | 开发实施步骤1确定方案包后 |
| 清除时机 | 方案包迁移至 `history/` 后 |

**用途:** 遗留方案扫描时排除当前执行的方案包

---

### MODE_FULL_AUTH

**描述:** 全授权命令激活状态

| 属性 | 值 |
|------|-----|
| 类型 | boolean |
| 触发 | `~auto` / `~helloauto` / `~fa` 命令 |
| 清除 | 命令完成或用户取消 |

---

### MODE_PLANNING

**描述:** 规划命令激活状态

| 属性 | 值 |
|------|-----|
| 类型 | boolean |
| 触发 | `~plan` / `~design` 命令 |
| 清除 | 命令完成或用户取消 |

---

### MODE_EXECUTION

**描述:** 执行命令激活状态

| 属性 | 值 |
|------|-----|
| 类型 | boolean |
| 触发 | `~exec` / `~run` / `~execute` 命令 |
| 清除 | 命令完成或用户取消 |

---

## 文件结构

### 方案包结构

```
plan/YYYYMMDDHHMM_<feature>/
├── why.md      # 变更提案
├── how.md      # 技术设计
└── task.md     # 任务清单
```

### 任务状态符号

| 符号 | 含义 |
|------|------|
| `[ ]` | 待执行 |
| `[√]` | 已完成 |
| `[X]` | 执行失败 |
| `[-]` | 已跳过 |
| `[?]` | 待确认 |

---

## 知识库结构

```
helloagents/
├── CHANGELOG.md          # 版本历史
├── project.md            # 技术约定
├── wiki/
│   ├── overview.md       # 项目概述
│   ├── arch.md           # 架构设计
│   ├── api.md            # API 手册
│   ├── data.md           # 数据模型
│   └── modules/          # 模块文档
│       └── <module>.md
├── plan/                 # 变更工作区
│   └── YYYYMMDDHHMM_<feature>/
└── history/              # 已完成变更归档
    ├── index.md          # 归档索引
    └── YYYY-MM/
        └── YYYYMMDDHHMM_<feature>/
```

## 评估维度数据

### 路由评估维度

| 维度 | 可选值 |
|------|--------|
| 意图类型 | 问答型 / 改动型 / 命令型 |
| 改动范围 | 无 / 微(≤2文件≤30行) / 小(3-5文件) / 中(多文件) / 大(架构级) / 不确定 |
| 需求明确度 | 明确 / 模糊 / 需澄清 |
| 上下文状态 | 无 / 追问中 / 选择中 / 确认中 |
| 命令修饰 | 无 / ~auto / ~plan / ~init / ~exec |
| EHRB风险信号 | 有 / 无 |

### 需求评分维度

| 维度 | 分值范围 | 衡量内容 |
|------|----------|----------|
| 目标明确性 | 0-3 | 任务目标是否清晰具体 |
| 预期结果 | 0-3 | 成功标准和交付物是否定义 |
| 边界范围 | 0-2 | 任务范围是否明确界定 |
| 约束条件 | 0-2 | 时间、性能、业务限制是否说明 |

**门槛:** 总分 ≥ 7 分方可继续
