# core

## 目的
定义全局规则（G1-G12）和统一智能路由机制，作为整个系统的核心框架。

## 模块概述
- **职责:** 全局规则定义、路由决策、输出格式规范、状态管理
- **状态:** ✅稳定
- **最后更新:** 2025-12-18

## 规范

### 需求: 全局规则体系
**模块:** core

提供完整的全局规则定义，确保系统行为一致性。

#### 场景: 语言与编码（G1）
用户在不同平台使用系统
- 输出语言按 OUTPUT_LANGUAGE 配置
- 编码统一 UTF-8
- Windows PowerShell 环境遵循特定语法约束

#### 场景: 不确定性处理（G3）
路由判定或技术方案存在不确定性
- 明确说明不确定因素
- 采用保守策略
- 列举假设并提供备选方案

#### 场景: 统一输出格式（G6）
任何阶段完成输出
- 使用规范格式模板
- 包含状态符号和阶段名称
- 文件清单使用纵向列表

### 需求: 统一智能路由
**模块:** core

根据用户请求自动选择最优工作流。

#### 场景: 路由决策
用户发送任意请求
- 执行语义分析、意图分类、范围评估、EHRB检测
- 按优先级匹配：命令模式 → 上下文响应 → 开发模式 → 咨询问答
- 输出路由结果和推理依据
