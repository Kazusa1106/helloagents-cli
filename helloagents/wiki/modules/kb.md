# kb

## 目的
管理项目知识库，包括创建、同步、审计和上下文获取。

## 模块概述
- **职责:** 知识库初始化、同步更新、质量检查、遗留方案处理
- **状态:** ✅稳定
- **最后更新:** 2025-12-16

## 规范

### 需求: 知识库初始化
**模块:** kb

创建或重建项目知识库。

#### 场景: 首次初始化
执行 ~init 命令且知识库不存在
- 扫描代码库获取项目信息
- 创建 CHANGELOG.md、project.md
- 创建 wiki/ 目录及核心文档
- 创建 history/index.md

#### 场景: 重建知识库
执行 ~init 命令且知识库存在重度问题
- 全面扫描代码库
- 重建所有知识库文件
- 大型项目分批处理（每批≤20个模块）

### 需求: 知识库同步
**模块:** kb

代码变更后同步更新知识库。

#### 场景: 模块规范更新
代码变更完成后
- 读取方案包 why.md 的核心场景
- 更新 `wiki/modules/<module>.md` 的规范章节

#### 场景: 按变更类型更新
代码变更完成后
- API变更 → 更新 wiki/api.md
- 数据模型变更 → 更新 wiki/data.md
- 架构变更 → 更新 wiki/arch.md
- 模块索引变更 → 更新 wiki/overview.md

### 需求: 遗留方案处理
**模块:** kb

管理 plan/ 目录下未执行的方案包。

#### 场景: 遗留方案扫描
方案包创建或迁移后
- 扫描 plan/ 目录
- 排除当前执行的方案包
- 检测到遗留方案时输出提示

#### 场景: 批量迁移
用户确认迁移遗留方案
- 询问迁移范围（全部/指定/取消）
- 更新任务状态为 [-]
- 迁移至 history/
- 更新 history/index.md

## API接口

### ~init / ~wiki
**描述:** 初始化或重建知识库
**输入:** 无
**输出:** 知识库命令完成格式
